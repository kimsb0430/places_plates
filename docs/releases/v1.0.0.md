# Places & Plates v1.0.0

Places & Plates v1은 여행지와 맛집의 사진, 장소, 방문 월과 개인 메모를 한곳에 남기는 개인 기록 서비스의 첫 안정 버전입니다.

## 주요 기능

- 맛집·여행지 기록 작성, 자동 저장, 공개 범위 선택과 삭제
- 게시 완료 기록의 전체 내용 수정, 사진 추가, 사진 순서·대표 사진 변경
- TUS 전송 동시성 제한과 순차 이미지 정제로 안정화한 다중 사진 업로드
- Google Places 장소 검색과 직접 장소 입력
- 목록·상세·장소 이력·Google 지도 기반 탐색
- 모바일·데스크톱 반응형 화면과 키보드 접근성
- EXIF·XMP·IPTC 제거, 원본 자동 삭제, 세 가지 공개 파생본과 픽셀 워터마크
- 소유자 세션, CSRF, PostgreSQL RLS, 공개 응답·보안 헤더 보호
- Vercel·Cloud Run 원자적 배포, 동일 커밋 운영 스모크, 백업·복구·비용 가드레일

## 운영 주소

- Web: https://placesplates.vercel.app
- API health: https://places-plates-api-481849639838.asia-northeast3.run.app/api/v1/health

## 알려진 한계

- 우클릭·드래그 억제와 워터마크는 일반적인 재사용을 어렵게 하지만 화면 캡처나 개발자 도구 접근을 완전히 차단하지 않습니다.
- HEIC·HEIF는 검증된 서버 디코더를 도입하기 전까지 JPEG 변환 안내를 제공합니다.
- v1은 단일 소유자 개인 페이지이며 회원별 독립 페이지와 커뮤니티 기능은 후속 버전 범위입니다.
- 공급자 관리 도메인을 사용하며 사용자 도메인은 별도 비용 승인 후 연결합니다.

## 日本語

Places & Plates v1は、旅行先と飲食店の写真、場所、訪問月、個人メモを一つに残す個人記録サービスの最初のstable releaseです。Restaurant・destination投稿、公開済み記録の本文・写真追加・代表写真編集、同時送信制限と逐次画像処理による複数写真upload安定化、Google Places検索、list・detail・place history・map閲覧、responsive UI、EXIF削除、original自動削除、pixel watermark、owner session・CSRF・RLS、Vercel・Cloud Runの同一commit deployment smokeを提供します。

右クリック抑制とwatermarkはscreen captureやdeveloper toolsを完全には防止しません。HEIC・HEIFはJPEG変換が必要で、v1はsingle owner archiveです。
