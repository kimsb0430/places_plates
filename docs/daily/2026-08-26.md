# 2026-08-26 Daily Report

## 한국어

- 목표: Cloud Run에서 ICC 색상 프로필이 있는 JPEG 정제 시 발생한 LCMS2 네이티브 라이브러리 오류를 제거한다.
- 완료: Google Buildpack 설정을 Java 21 다단계 Dockerfile로 교체하고 실행 이미지에 `liblcms2-2`를 설치했다. 애플리케이션은 UID 10001 비루트 사용자로 실행하며 CI가 실제 이미지를 빌드해 `liblcms2.so.2`와 실행 사용자를 검사하도록 추가했다.
- 중요 파일: `backend/Dockerfile`, `backend/.dockerignore`, `.github/workflows/verify.yml`, `scripts/verify-cloud-run-container.ps1`, `PROJECT_STRUCTURE.md`, `docs/DEPLOYMENT_CHECKLIST.md`
- 검증: 비밀 검사, 컨테이너 계약 검사, 프론트 lint·타입 검사·Vercel 및 Sites 빌드와 공개 산출물 검사, 백엔드 전체 테스트·배포 JAR 생성이 로컬에서 통과했다. 로컬 환경에는 Docker 명령이 없어 실제 컨테이너 빌드·라이브러리 검사는 GitHub CI에서 수행한다.
- 결정: Cloud Run 백엔드는 암묵적인 Buildpack 시스템 패키지에 의존하지 않고 저장소의 Dockerfile을 배포 기준으로 사용한다.
- 위험: 수정 리비전 배포 전까지 ICC 색상 프로필을 읽는 JPEG 정제 요청은 같은 오류로 실패할 수 있다. 기존 실패 초안과 임시 업로드는 운영 만료 정책 범위에서만 유지된다.
- 다음 작업: 수정 PR 병합과 Cloud Run 재배포 후 기존 실패 항목을 재시도하고 정제·파생본 생성·READY 전환을 운영에서 확인한다.

## 日本語

- 目標: Cloud RunでICC color profileを含むJPEGをsanitizeするときに発生するLCMS2 native library errorを解消する。

- 重要ファイル: `backend/Dockerfile`、`backend/.dockerignore`、`.github/workflows/verify.yml`、`scripts/verify-cloud-run-container.ps1`、`PROJECT_STRUCTURE.md`、`docs/DEPLOYMENT_CHECKLIST.md`
