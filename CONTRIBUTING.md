# Contributing

1. Read `AGENTS.md` and the three source-of-truth design documents.
2. Update local `main` and create a `codex/<scope>` branch.
3. Keep frontend and backend code in their documented domain structures.
4. Run `scripts/check-secrets.ps1` and all available verification before committing.
5. Use the dated English/Korean/Japanese commit subject format.
6. Push the branch and open a pull request targeting `main`.
7. The repository owner reviews and merges with **Rebase and merge**.
8. After merge, synchronize `main`, confirm CI, and follow `docs/DEPLOYMENT_CHECKLIST.md` for any deployment.
